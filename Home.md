# Roblox Setup

The rulebook for our kids' Roblox games (ages 5-18). Every game follows these notes, and every test that teaches us something lands in [[Lessons]] and then updates the matching rule.

## Rulebook
| Note | What it covers | Status |
|---|---|---|
| [[Brainstorm Rules]] | Research, go wide, cut, score, pitch three | Draft, not used yet |
| [[Game Design Rules]] | Pitch card, first minute, grind budget, odds, hooks, testing | Tested once (bot) |
| [[World Rules]] | Layout, layers and depth, lighting, readability, performance | Draft, lighting untested |
| [[UI Rules]] | Chunky Pop look, HUD cap, painted icons, porting UI | Paused, "starting to be perfect" |
| [[Pet Rules]] | Pet card, design rules, rarity ladder, concept → image-to-3D, rigs, mutations | Tested on one pet (Frostfox) |
| [[Animation Rules]] | Motion set, shows, pets, world motion, camera | Draft, timings untested |
| [[Sound Rules]] | Sound meanings, juice, music, soundscape, settings, sources | Draft, not used yet |
| [[Code Rules]] | One owner per thing, Init/Start, remotes, saving, Studio work | Draft, not used yet |
| [[QA Rules]] | Three reviewers, kid lens, break it, devices, security, GO / NO-GO | Draft, from Boo Town's QA |
| [[Game Page Art]] | Icon and 6 thumbnails, the fixed prompts | Approved |
| [[Lessons]] | What went wrong and the rule that changed | Ongoing |

## The pipeline
1. **Brainstorm**: research, three pitches, the user picks ([[Brainstorm Rules]])
2. **Pitch card** ([[Game Design Rules]] › 1), then **pets first**: roster, style test, concepts ([[Pet Rules]] › 5)
3. **HTML prototype** with a playtest bot and timer panel ([[Game Design Rules]] › 12), world built to [[World Rules]]
4. **UI, motion and sound pass** ([[UI Rules]], [[Animation Rules]], [[Sound Rules]])
5. **QA on the prototype**, GO before porting ([[QA Rules]])
6. **Port plan + port to Studio** ([[Code Rules]])
7. **UI pass on phone, tablet, PC**
8. **QA in Studio**, multi-player test, GO / NO-GO ([[QA Rules]])
9. **Page art** ([[Game Page Art]])
